# 代码级剖析与解决方案：为什么生成码与 GT 码不一致

2026-10-14。前置：[REPORT.md](REPORT.md)（四 regime 基线）→ [CAUSE_ANALYSIS.md](CAUSE_ANALYSIS.md)
（三层分解）→ 本文（代码机制 + 新实验 + 方案矩阵）。新增实验脚本 `solver_sweep.py`，
结果 `sweep_tf100_2L.json` / `sweep_tf10_l6_film.json`。

## 1. 代码机制：推理/训练链路上的五个误差源

### 1.1 `_integrate` 的真面目：末端读数是"自复合 K-1 步后的最后一次预测"

`arch/flowmatch_vqvae_controller.py:1199`（target 模式）：

```
for step in range(K):   t = step/K
    velocity = (pred(z_t, t) - z_t) / (1-t)     # pred = 模型输出
    z += (1/K) * velocity
```

代数上 `(1/K)/(1-step/K) = 1/(K-step)`，最后一步（step=K-1）恰好 `z_new = pred`——
**最终输出就是模型在第 K-1 个自生成中间态上、于 t=(K-1)/K 处的一次查询**。
K 越大，路径上"模型喂自己"的次数越多。

新实验（`solver_sweep.py` §A，TF 锚定、std0、12 clips × 120 帧）：

| Euler K | 2 | 4（官方协议） | 8 | 16 | 32 |
|---|---:|---:|---:|---:|---:|
| 2L 码匹配 | **0.380** | 0.377 | 0.366 | 0.352 | 0.337 |
| FiLM 码匹配 | **0.293** | 0.283 | 0.264 | 0.245 | 0.230 |

单调下降，每步自复合约 -0.4%~-1%。**官方 K=4 相对最优（K=2）只差 ~1pp，不是问题所在**；
但它证明"自复合"这一机制在求解器内部同样生效（幅度较轻，因为锚点仍是 GT）。

### 1.2 训练目标：连续 MSE，码身份从不被优化

`compute_loss` 的 flow loss 是归一化 latent 空间上的 MSE（velocity 或 target 模式）。
没有任何项关心"落在哪个 Voronoi 胞元"。当条件分布多峰时，MSE 最优解是条件均值——
它恰恰可以落在胞元边界附近。**码身份对训练而言是不可见的量**。

### 1.3 多峰性实验：连续空间以偏差为主，码空间以方差为主

`solver_sweep.py` §C（每帧 8 个独立 z0）：

| | 2L | FiLM |
|---|---:|---:|
| 单样本码匹配 | 0.316 | 0.236 |
| 8 样本码一致率（pairwise） | 0.485 | 0.395 |
| 8 样本中至少一个对（any） | 0.621 | 0.546 |
| 8 样本均值 vs 单样本匹配 | **0.370 vs 0.316** | **0.280 vs 0.236** |
| ‖均值−GT‖ / ‖单样本−GT‖ | 0.90 | 0.88 |

两个结论：(a) 平方误差里 **~81% 是系统性偏差、~19% 是采样方差**（均值法把误差缩小
到 0.88-0.90 倍，Jensen 余量即方差占比）；(b) 但**码空间里方差被放大**——胞元半宽
中位仅 0.097，而样本围绕均值的散布 rms 达 0.51-0.59，因此"落在哪个胞元"有巨大随机性。
这解释了为什么"均值更接近 GT"却仍不能解决码翻转：**分辨率太小，方差足以跨界**。

### 1.4 采样噪声：单步 -5pp，闭环无感

`sample_transport_noise_like`（latent_transport_std 各维 0.06~4.7，强各向异性）注入
std1 噪声：K=4 单步匹配 2L 0.377→0.322、FiLM 0.283→0.235（**-5pp**）；
但闭环（K=240）匹配不变（0.056/0.047）。**闭环误差由锚点漂移主导，注入噪声可忽略**。

### 1.5 反馈链：`feedback_state` 每步 clip→requantize→decode，锚点误差复利

`feedback_state:1129`：每帧把预测切回码本再解码，作为下一帧的 prev/history/观测。
CAUSE_ANALYSIS 的 GT 重锚定扫描已给出复利曲线：**第 1 个自反馈帧即损失 16%**，
半衰期 ~8 帧，240 帧剩 15-16%，饱和于有界吸引子。

### 1.6 codec 自身往返：37.8%（仅对"重编码"链路重要）

`encode→decode→re-encode` 只有 37.8% 槽保持码。这对控制器**直接**预测路径不是天花板
（模型是 latent→latent，不经过重编码），但对任何"解码再编码"的链路（观测噪声重渲染、
未来可能的 code-LM 数据管线）是硬上限。

### 1.7 GT 运动本身的码统计（新数据）

逐帧：**63.1% 的槽换码**；非零位移中位 **0.146** ≈ 码字最近邻间距 0.154；
胞元边界距离（margin）分位 p10/p50/p90 = 0.026/0.097/0.387。
即 GT 码流本身就是高换手率的离散序列——**"码字稳定"从来不是这个表示空间的性质**。

## 2. 因果层级（量化权重）

```
码匹配 ≈ P(‖ε‖ 在位移方向上 < margin)
   ε = 单步误差（中位 0.077/0.091，均值 0.125/0.141）  ← 实测
   margin = 到胞元边界的距离（中位 0.097，p10 0.026）
```

| 层级 | 机制 | 证据 | 贡献 |
|---|---|---|---|
| **R1 分辨率错配** | 单步误差(0.08-0.14) ≈ 半胞元(0.10-0.19) | §2.2 误差分布 vs §1.7 margin 分布 | **单步错误的 ~60-70%**（几何必然） |
| **R2 目标错配** | MSE 无 margin 意识；多峰均值贴边 | §1.2、§1.3（bias 81%） | 残余单步的相当部分 |
| **R3 暴露偏差** | 纯 TF 训练（p=0 设计决定），闭环无纠正 | K=1→2 损失 16%，半衰期 8 帧 | **闭环 240 帧里 ~85% 的损失** |
| R4 求解器自复合 | K 步 = K-1 次自喂 | §1.1 单调 -1~2%/倍增 | 小（官方 K=4 仅 -1pp） |
| R5 采样噪声 | 各向异性 transport_std 注入 | §1.4 | 单步 -5pp；闭环无感 |
| R6 codec 往返 | 重编码链 37.8% | REPORT | 仅对重编码链路 |

**一句话**：单步时是**几何问题**（模型精度与码格同量级，R1+R2）；闭环时是**动力学问题**
（自反馈锚点复利，R3）。R4/R5 是二阶效应，R6 与本问题无关。

## 3. 解决方案矩阵

按"目标是什么"分组。先明确：**若目标仍是运动质量+风格准确率，码匹配不是有效指标**
（码差运动影响仅 1-3cm；FiLM 模型码匹配更低却风格/跨风格更好）——方案 A0 是正解，
其余仅在"确实需要码保真"（如 code-LM、码级编辑、码空间先验）时才值得做。

| # | 方案 | 机制/改动 | 预期 | 成本 | 风险 |
|---|---|---|---|---|---|
| **A0** | **重设指标口径**（推荐） | 评估不用 GT 码一致率；运动/风格指标为准。文档化"码流不可复现"为表示层性质 | 消除误报 | 零 | 无 |
| B1 | 显示路径去量化 | 交互/展示用 `--no-requantize`（已有开关） | 显示无码跳变 | 零 | 偏离评估协议（仅显示） |
| B2 | 求解器 K=2 | 码保真最优（+1pp vs K=4），且省一半算力 | 单步 +1pp | 零 | 偏离官方 K=4 协议 |
| C1 | 观测量噪声标定 | 按实测反馈漂移尺度重扫 `OBS_NOISE_STD`（0.25/0.5/0.75），现状 0.5 | 或延长半衰期 | 低（10ep 试点） | 需 A/B 运动质量 |
| C2 | 短程自反馈增强 | 训练时以概率 p 用模型自身 1-2 步输出替代 GT 观测（比完整 rollout 温和；仓库已否决完整 rollout） | 直接对抗 R3 | 中（训练+验证） | 运动质量回退（需以 jitter/FS/MPJPE 为闸门） |
| C3 | margin 感知辅助损失 | 对 GT 目标码 margin 大的槽加 hinge：把预测推向胞元内部（小权重） | 单步 +数 pp | 低-中 | 轻微扭曲连续预测；与现有 loss 需调平衡 |
| D1 | 更粗的码本 | 重训 VQ（更少码/更大码格）抬高 R1 天花板 | 码稳定大幅提升 | **极高**（冻结 VQ 是全仓负载，全链路重做） | 运动质量未知；不建议 |

**不建议**：完整 rollout 训练（历史 A/B 已证损害运动质量）、donor（已移除）、
为码保真牺牲风格/运动指标。

## 4. 建议的下一步（按性价比排序）

1. **A0**：把"码流不可复现"写进评估文档（本目录三份报告已可作为引用）。
2. **B2**：若在意码保真，官方协议里加一个 K=2 的旁路对比（零成本，已有数据：+1pp）。
3. **C1**：`OBS_NOISE_STD` 0.25/0.5/0.75 三档 10ep 试点（每次 ~32min），只看
   闭环 L2sig/match 半衰期与运动质量——**这是唯一便宜且直接作用于 R3 的现有旋钮**。
4. **C2/C3**：仅在 C1 不足且码保真被证明有下游需求时实施；C3 先做离线模拟
   （用探针数据估计 hinge 权重上限）再训练。
