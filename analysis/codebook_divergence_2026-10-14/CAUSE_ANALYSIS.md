# 码本跳变根因分析（为什么生成码与 GT 码不一致）

> 复审限定（2026-10-14）：下文的“物理不可能/硬上限”“运动层面良性”及部分因果排除不能由这些探针推出。到次近码平面不一定等于真实最近边界；扰动范数超过安全半径也不意味着必定跨界。原始记录保留，更正与独立validation结果见 [AUDIT.md](../vq_code_stability_2026-10-14/AUDIT.md)。

2026-10-14。承接 [REPORT.md](REPORT.md)（四 regime 基线）。本文件新增两轮针对性探针并给出
定量因果分解。

**问题框定**：本问题指"生成帧的 32 槽量化码（4 维/槽 × 2048 码本）与对应 GT 帧的量化码
不一致"。先分清三层，混在一起谈会导致错误归因：

| 层 | 问题 | 本报告答案 |
|---|---|---|
| L0 codec | 量化链自身能保住码吗？ | **不能**：decode→re-encode 一圈后仅 37.8% 的槽保持码；62.2% 翻转 |
| L1 单步 | 给足 GT 锚点、模型最优条件下，码准度多少？ | **0.379（2L）/ 0.293（film）**，受 L0 与模型回归精度共同限制 |
| L2 闭环 | 自反馈下码准度如何衰减？ | **一步自反馈后单调衰减，K=8 帧剩 49%，K=240 剩 15-16%，饱和于有界吸引子** |

## 一、方法（新增两个探针）

`codebook_cause.py`（本目录，本轮新增）：

1. **几何**：对 12 条 test clip（240 帧）做 codec-only 的 `encode(GT)→decode→re-encode`，
   测每槽码的保持率、翻转目标码在 GT latent 距离排序中的 rank、码本码字两两最近邻间距
   （c2c NN）、以及位移与 Voronoi 边界余量的关系。
2. **稳定/过渡槽分解**：把逐帧槽观测按"GT 码从上一帧是否变化"分组，分别统计匹配率
   （roundtrip / tf / rollout），回答"是保不住稳定码，还是造不出新码"。
3. **闭环刷新扫描（关键实验）**：跑官方 rollout 语义，但每 K 帧把反馈状态（prev latent、
   history、观测 motion）重新锚定到 GT 量化状态。K=1 ≡ 单步流形（等价 reconstruct），
   K=240 ≡ 完整 rollout。match(K) 曲线即"离开 GT 吸引域的步数"。
4. **单步回归精度**：TF 条件下模型连续输出与目标码字 z_q(GT) 的逐槽距离分布，用来和
   码本间距直接比较。

轨迹块全程用 GT（与基线探针一致），因此全部数字都排除了轨迹预测误差的贡献。

## 二、结果

### 2.1 几何：码本自身（两模型共用同一冻结 VQ，数字完全相同）

| 量 | 值 |
|---|---:|
| roundtrip 码保持率 | **0.378** |
| roundtrip 位移（码字-码字距离，非零时） | ≥ 1 个 NN 间距（离散跳变，0.5-1× 区间观测数为 0） |
| 码本 NN 间距 c2c（p25/中位/p75） | 0.086 / **0.154** / 0.308 |
| GT 码逐帧切换率 | **63.1% 槽/帧**（20.2/32） |
| GT 稳定槽占比 | 0.368-0.369 |
| 稳定槽 vs 过渡槽的码边界余量 | 0.286 vs 0.139 |

读法：这个 codec 的码字排布很密（中位间距 0.154，且 5% 分位仅 0.039），**GT 自己的码每帧
就有 63% 在换**；decode→re-encode 一圈后 62% 的槽跳码，且跳变是"离散的"——要么原码，
要么跳到 ≥1 个间距之外（不存在小幅漂移的中间态）。近邻码解码后运动差异很小
（whole-codeword code_impact 仅 1.21cm），即码身份脆弱但**视觉代价小**。

### 2.2 单步（TF，GT 锚定）：模型精度 ≈ 半个码格

| | 2L (tf100) | 6L FiLM |
|---|---:|---:|
| 单步码匹配 match | 0.379 | 0.293 |
| — 稳定槽保持率 | **0.628** | 0.476 |
| — 过渡槽新码正确率 | **0.235** | 0.188 |
| | | |
| 逐槽连续预测误差中位（vs z_q(GT)） | **0.077** | **0.091** |
| 同误差 p75 / 均值 | 0.146 / 0.125 | 0.167 / 0.141 |
| 码本 NN 间距中位（参照） | 0.154 | 0.154 |
| 生成码 rank≥3 占比（全体槽观测） | 0.427 | 0.504 |
| 码差运动影响 code_impact | 2.62cm | 2.83cm |

**定量闭环**：模型单步回归误差的中位数（0.077/0.091）≈ 码格间距 0.154 的 **1/2**，
即恰好落在"胞元半径"量级（平均半余量 ≈ 0.077-0.095）。因此**单步就有约 60-70% 的槽
被判到隔壁胞元，这是算术必然，不是 bug**：模型预测精度与量化单元尺寸同量级时，
码身份不可分辨。稳定槽的保持（0.63）明显好于过渡槽的产生（0.235）——低密度区码能守住，
高密度区（过渡、margin 0.139）码本质上无法从预测中恢复。

### 2.3 闭环刷新扫描：衰减从第一步开始，饱和于有界吸引子

match(K)（K=1 单步锚定 → K=240 全闭环）：

| K | 1 | 2 | 4 | 8 | 16 | 32 | 64 | 240 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| **2L** match | 0.375 | 0.315 | 0.248 | 0.184 | 0.134 | 0.101 | 0.078 | **0.056** |
| 2L L2sig | 1.37 | 1.51 | 2.40 | 3.32 | 5.18 | 7.04 | 6.60 | 8.70 |
| **film** match | 0.287 | 0.239 | 0.187 | 0.140 | 0.104 | 0.082 | 0.064 | **0.047** |
| film L2sig | 1.30 | 1.43 | 2.38 | 3.92 | 5.06 | 7.86 | 6.70 | 10.51 |

（L2sig = raw latent 空间 ‖生成−GT‖；与归档 REPORT 表中 normalized L2sig≈15 为不同口径，
量级差约 ×2。）

- **无平台期**：K=2 相对 K=1 已损失 16%（0.375→0.315）。不存在"前几步能自恢复"的盆地；
  第一步自反馈就在积累误差。
- **半衰期 ≈ 8 帧**：K=8 保留 49%（0.184/0.375）；K=32 剩 27%；K=240 剩 15%。
  衰减在对数尺度近似线性（每翻倍 ×0.75-0.78），是典型的暴露偏差复合曲线。
- **有界饱和**：L2sig 在 ~7-10 raw 处饱和（240 帧内没有发散），即模型没有"漂散"，而是
  收敛到自己的一条合理轨迹上——码流与 GT 码流变成统计上无关的两个序列
  （归档探针 lag 曲线平坦，全 lag 档 match ≈0.03-0.06）。
- **完全体的稳定槽都保不住**：rollout 档 stable-slot 保持率仅 0.076-0.081（2L/film），
  过渡槽 0.031-0.041；gen_keeps_prev ≈ gen_new ≈ 0.03——既不留旧码也不产对码，
  状态已整体离开 GT 码邻域。

### 2.4 已排除的候选原因（每项都有对照数据）

| 候选 | 证据 | 判定 |
|---|---|---|
| 每步量化注入噪声 | K=1（每步都 requantize）单步匹配仍有 0.375/0.287 | 排除 |
| 训练/推理观测口径差（GT raw motion vs decode(z_gt)） | tf vs reconstruct 匹配差 ≤0.4pp（0.379/0.375；0.293/0.287） | 排除 |
| 采样噪声（std 1） | rollout match std0 = std1（0.056/0.047 完全相同） | 排除 |
| 轨迹条件误差 | 设计上全程 GT 轨迹 | 排除 |
| "只是贴边 tie 抖动" | 翻转码 rank≥3 占比 0.43-0.50；大余量桶翻率仍 0.46 | 排除（不止贴边） |
| 闭环漂移由某个单步 bug 引起 | K=1→K=240 单调平滑曲线，每档衰减比例一致 | 排除（是复合效应） |

## 三、因果链总结

```
L0 codec：码本密（中位间距0.154）+ GT 码 63%/帧 切换
   └─ decode 往返后 62% 槽跳码；近邻码运动代价小(1.2cm)
L1 单步：模型回归误差中位 0.077-0.091 ≈ 0.5×码间距
   └─ 单步码准度被压到 0.29-0.38（稳定槽 0.48-0.63 / 过渡槽 0.19-0.24）
L2 闭环：自身输出作为观测 → 分布外状态 → 每步误差复利
   └─ 半衰期 ~8 帧，240 帧剩 15%，饱和于有界吸引子（L2sig ~8-10，不发散）
```

**一句话**：码字与 GT 不一致不是某个模块故障，而是"连续 flow 控制器 + 无记忆最近邻
量化器"在此码本分辨率下的结构性质——单步精度（≈半个码格）决定了码身份不可分辨，
闭环让误差以 ~8 帧半衰期复利到有界吸引子。**运动层面它是良性的**（近邻码代价 1-3cm，
风格匹配 87%、交互视频动作连贯）。（⚠️ 复审更正：原文此处断言"码层面 GT 复现物理上
不可能"——该结论不由本探针支持，见文首限定。）

## 四、含义与建议

1. **评估口径**：任何要求"生成码与 GT 码逐帧一致"的指标（如 code 对齐率、码级 PSNR）
   都不适合评价模型质量（⚠️ 复审更正：原文"硬上限 ~0.38"来自本探针 12-clip 的 codec
   往返保持率，是经验值而非信息论上限，且测集不是 untouched 封存集）；运动/风格指标
   （现有封存协议）是正确口径。
2. **code-alignment loss**（仓库已有 `tests/test_code_alignment.py`）：若目标是把生成码
   拉向 GT 码，注意 L1 的上限与 L2 的暴露偏差——它只能改善单步，不能解决闭环衰减；
   闭环保真要靠多步/DAgger 类训练（但仓库既定结论：rollout 训练损害运动质量，见
   `analysis/rollout_training_ab`、DONOR_REMOVAL 记录）。
3. **codec 设计**（若将来重训 VQ）：增大每槽 code_dim / 减少码数 / 提高码间距可抬高
   L0/L1 天花板；当前 5% 分位间距仅 0.039 的密区是过渡槽跳变的温床。
4. **显示质量**：单步跳码的运动代价只有 1-3cm，且交互默认 requantize——与本仓库早先
   结论（"量化阶梯不是显示抖动主因"，`docs/INTERACTIVE_LABEL_CONTROL.md`）一致。
   显示抖动问题不应再归因于码本跳变。
5. **两个模型对比**：FiLM 模型单步码准度更低（0.293 vs 0.379）、闭环漂移略大
   （L2sig@240 10.51 vs 8.70），但风格/跨风格指标显著更好——再次印证它的表达收益
   不来自码级复现。
